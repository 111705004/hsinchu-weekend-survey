# 新竹人心理測驗

9 題情境心理測驗，測出 8 種新竹人角色，領一張有插圖的角色卡（可存成限動圖片）。
途中有幾題真心話、一題推薦店家；最後留 Email 可以抽神秘禮物、登記搶先體驗。

- 測驗：https://wingofhsinchu.github.io/
- 後台：https://wingofhsinchu.github.io/admin.html
（要管理密碼）

網頁放在 GitHub Pages，答案存進 Google 試算表。

## 設定（只要做一次）

### 1. 建 Google 試算表和接收端
1. 開一份新的 Google 試算表，取名例如「新竹人心理測驗」。
2. 選單「擴充功能 → Apps Script」。
3. 把 `apps-script/Code.gs` 的內容全部貼上，取代原本的程式碼，按存檔。
4. 上方函式選單選 `setup`，按「執行」。第一次會要求授權，用自己的 Google 帳號允許（會看到「Google 尚未驗證這個應用程式」，按「進階 → 前往」即可，因為這是你自己寫的程式）。試算表會多出五個分頁：欄位說明、回覆、口袋名單、抽獎名單、中獎紀錄。「欄位說明」解釋每一欄的意思。
5. 左邊齒輪「專案設定」→ 最下面「指令碼屬性」→ 新增：名稱 `ADMIN_KEY`，值是後台密碼（**至少 12 個字**，不要用生日或常用密碼）。
6. 右上「部署 → 新增部署作業」→ 齒輪選「網頁應用程式」：執行身分「我」，誰可以存取「所有人」→ 部署。
7. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）。

### 2. 把網址貼到網站
在 GitHub 上打開 `assets/config.js` → 右上鉛筆圖示編輯：
- `SCRIPT_URL`：貼上剛剛的網址
- `winners`：抽幾位
- `deadline`：抽獎截止日，例如 `'12/15'`
- `announce`：怎麼公布，例如 `'12/20 以 Email 通知中獎者'`

按「Commit changes」。一兩分鐘後網站就會更新。

### 3. 測一次
自己從頭玩一次測驗、留 Email，確認試算表「回覆」和「抽獎名單」都多一列，後台輸入密碼看得到數據。確認後把測試那列刪掉再發出去。

### 4. 分享給團隊
- 試算表右上「共用」加隊友，權限給「檢視者」就好，只有負責人給「編輯者」。
- 後台密碼私下傳（不要貼在公開群組或 repo 裡）。

### 改了 Code.gs 之後
「部署 → 管理部署作業 → 鉛筆 → 版本選『新版本』→ 部署」。網址不變；只存檔不會生效。

## 抽獎與 Email
- 只有一個勾選：「參加抽獎＋搶先體驗」。留 Email 並勾選才會進抽獎池，同時也列入搶先體驗名單。
- Email 存在「抽獎名單」分頁，只記日期、插在隨機位置，跟「回覆」分頁對不起來，答案維持匿名。
- 後台「抽出得主」按鈕：同一個 Email 只算一次、中過的不會再中；按兩次才真的抽，結果寫進「中獎紀錄」。
- 測驗頁承諾「回信說要取消搶先體驗就刪除」，收到這種回信記得到「抽獎名單」把那個 Email 刪掉。

## 安全性
做了的：
- Apps Script 加了 `@OnlyCurrentDoc`，只能存取這一份試算表，碰不到你雲端硬碟裡的其他檔案。
- 測驗頁和後台都有 `noindex`，Google 不會把它們列進搜尋結果。
- 後台資料要密碼，密碼錯 10 次鎖 15 分鐘；密碼太短（少於 12 字）一律拒絕。
- 全站每分鐘最多收 60 份，擋灌票程式；另有隱藏欄位擋機器人。
- 寫進試算表和匯出 CSV 時，`=`、`+`、`-`、`@` 開頭的文字會加 `'`，避免公式注入。
- 後台把填答內容當純文字顯示，不會執行裡面的程式碼。
- 公開的只有「總份數＋各類型人數」（結果卡用）；Email 和答案都要密碼才讀得到。

仍要注意的：
- 網址是公開的，任何人都能填，也能故意亂填。後台會標出「不到 1 分鐘」的份數，分析時可以排除。
- 有心人可以故意輸錯密碼讓後台鎖 15 分鐘（資料不會外流，等一下就好）。
- 真正的資料在 Google 試算表，它的安全取決於你的 Google 帳號：開兩步驟驗證，共用時只給需要的人。
- 這個 repo 是公開的，不要把密碼、試算表連結寫進任何檔案。`SCRIPT_URL` 公開沒關係，它只能寫入、不能讀資料。

## 檔案
- `index.html`：測驗頁
- `admin.html`：數據後台（圖表、交叉表、質化回答、口袋名單、抽獎、匯出 CSV）
- `assets/questions.js`：題目與 8 種角色。**改題目請保留 id**，不然新舊資料對不起來
- `assets/art.js`：角色插圖與禮物盒
- `assets/config.js`：接收端網址與抽獎設定
- `assets/survey.js`、`assets/admin.js`、`assets/style.css`：畫面與邏輯
- `apps-script/Code.gs`：貼到 Apps Script 的接收端

## 本機測試
```
python3 -m http.server 8001
```
打開 `http://localhost:8001`。`SCRIPT_URL` 留空時，答案只存在該瀏覽器；後台按「改看這台裝置暫存的回覆」可以看測試畫面。
