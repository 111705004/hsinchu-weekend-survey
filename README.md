# 新竹人週末調查

9 題心理測驗＋真心話＋口袋名單，填完會跑出一張「新竹人卡」，留 Email 可以參加抽獎。
網頁放在 GitHub Pages，答案存進 Google 試算表，團隊打開試算表或後台就能看數據。

- 問卷：`https://<帳號>.github.io/<repo>/`
- 後台：`https://<帳號>.github.io/<repo>/admin.html`（要管理密碼）
- 發不同管道時加參數，例如 `?src=ig`、`?src=threads`、`?src=line`，後台可以依來源篩選。

## 設定（約 10 分鐘，只要做一次）

### 1. 建 Google 試算表和接收端
1. 開一份新的 Google 試算表，取名例如「新竹人週末調查」。
2. 上方選單「擴充功能 → Apps Script」。
3. 把 `apps-script/Code.gs` 的內容全部貼上，取代原本的程式碼，存檔。
4. 上方函式選單選 `setup`，按「執行」。第一次會要求授權，用你自己的 Google 帳號允許。試算表會多出四個分頁：回覆、口袋名單、抽獎名單、中獎紀錄。
5. 左邊齒輪「專案設定」→ 最下面「指令碼屬性」→ 新增屬性：名稱 `ADMIN_KEY`，值是你們自己訂的後台密碼（長一點）。
6. 右上「部署 → 新增部署作業」→ 類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
7. 按部署，複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）。

### 2. 把網址貼到網站
打開 `assets/config.js`，把網址貼到 `SCRIPT_URL`。順便填抽獎設定：
- `winners`：抽幾位
- `deadline`：抽獎截止日，例如 `'2026/12/15'`
- `announce`：怎麼公布，例如 `'12/20 以 Email 通知中獎者'`

存檔、commit、push，一兩分鐘後網站就會更新。

### 3. 分享給團隊
- 試算表右上「共用」加隊友，大家就能直接看原始資料。
- 後台密碼私下傳給隊友。
- 「抽獎名單」分頁有 Email，只分享給需要聯絡中獎者的人也可以：另開一份只有回覆分頁的副本給其他人。

### 改了 Code.gs 之後
要「部署 → 管理部署作業 → 編輯 → 版本選『新版本』→ 部署」，網址不變。只存檔不會生效。

## 抽獎怎麼運作
- 留 Email 並勾選同意才會進抽獎名單；不留也能送出，但不能抽。
- Email 存在「抽獎名單」分頁，只記日期、插在隨機位置，跟「回覆」分頁對不起來，答案維持匿名。
- 後台的「抽出得主」按鈕：同一個 Email 只算一次、已中獎的不會再中。按兩次才會真的抽（防誤觸），結果寫進「中獎紀錄」分頁。建議全隊一起看著按，或螢幕錄影存證。
- 活動結束、寄完獎品後，記得刪除「抽獎名單」分頁裡的 Email（問卷上有這樣承諾）。

## 檔案
- `index.html`：問卷
- `admin.html`：數據後台（圖表、交叉表、質化回答、口袋名單、抽獎、匯出 CSV）
- `assets/questions.js`：題目與 8 種新竹人卡。**改題目請保留 id**，不然新舊資料對不起來
- `assets/config.js`：接收端網址與抽獎設定
- `assets/survey.js`、`assets/admin.js`、`assets/style.css`：畫面與邏輯
- `apps-script/Code.gs`：貼到 Apps Script 的接收端

## 本機測試
```
python3 -m http.server 8001
```
打開 `http://localhost:8001`。`SCRIPT_URL` 留空時，答案只存在該瀏覽器；後台按「改看這台裝置暫存的回覆」可以看測試畫面。

## 注意
- 網站是公開網址，任何人拿到連結都能填；後台的資料要密碼才讀得到。
- 結果卡的「第幾位、多少人同型」是即時計算的趣味數字。
- 後台會標出填答不到 1 分鐘的份數，分析時可以考慮排除。
